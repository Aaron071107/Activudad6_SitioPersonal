# Actividad 6 — Portafolio personal

Sitio web académico responsivo realizado con **HTML5, CSS3 y Bootstrap 5**.

## Contenido
- `index.html`: página de inicio con carrusel, Sobre mí, proyectos y contacto.
- `css/estilos.css`: diseño personalizado y ajustes responsivos.
- `js/script.js`: validación local del formulario de demostración.

## Nota sobre el formulario
No envía mensajes ni almacena información; solamente valida los campos en el navegador.

## Imágenes
Las fotografías de ejemplo se cargan desde Unsplash mediante URLs públicas. Para una entrega con recursos locales, reemplázalas por imágenes cuya licencia hayas revisado y guardado en el proyecto; conserva la atribución correspondiente cuando aplique.
